        **SoC = System on Chip (시스템 온 칩)** 이야.

쉽게 말하면 **컴퓨터에 필요한 여러 부품을 하나의 칩 안에 모아놓은 것**이야.

예를 들어 일반적인 컴퓨터에는 CPU, GPU, 메모리 제어기, 통신장치 등이 따로 있거나 여러 칩으로 나뉘어 있는데, SoC는 이런 기능들을 한 칩에 많이 통합해.

```text
┌─────── SoC ────────┐
│                                   │
│   CPU       → 계산/프로그램 실행  │
│   GPU       → 그래픽/병렬 계산    │
│   NPU       → AI 연산            │
│   Memory    → 메모리 제어         │
│   USB       → 주변기기 연결       │
│   Wi-Fi     → 통신               │
│   Camera ISP→ 카메라 영상 처리    │
│   I/O       → 센서 등과 연결      │
│                                   │
└──────────────── ─┘
```

### MCU랑 비교하면

네가 전에 배운 **MCU**도 사실 비슷한 철학이야.

| | MCU | SoC |
|---|---|---|
| 목적 | 기계/장치 제어 | 하나의 컴퓨터 시스템 구성 |
| CPU 성능 | 비교적 낮음 | 비교적 높음 |
| OS | 없어도 됨 | Linux/Android 등을 많이 사용 |
| 예 | STM32, ESP32 | Raspberry Pi의 Broadcom 칩, NVIDIA Jetson의 Tegra |
| 로봇에서 | 모터, PWM, 센서 제어 | ROS2, AI, 카메라, SLAM |

예를 들어 로봇을 만든다면 이런 구조가 가능해.

```text
카메라 ──┐
LiDAR ───┼──→ [ SoC ]
IMU ─────┘       │
                 │ ROS2 / SLAM / AI
                 ↓
               [ MCU ]
                 │
              PID 계산
                 │
                PWM
                 ↓
               Motor
```

즉 **SoC는 로봇의 '고수준 두뇌'**, MCU는 **모터와 센서를 실시간으로 다루는 '현장 제어 담당'**이라고 생각하면 이해하기 쉬워.

그리고 중요한 점 하나: **Raspberry Pi 자체가 SoC는 아니야.** Raspberry Pi라는 보드 위에 **Broadcom SoC가 올라가 있는 것**이야.
