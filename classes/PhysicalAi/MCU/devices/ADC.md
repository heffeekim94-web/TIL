**ADC는 아날로그 전압을 MCU가 이해할 수 있는 숫자로 바꿔주는 장치**야.

ADC = **Analog-to-Digital Converter**, 즉 **아날로그 → 디지털 변환기**야.

예를 들어 어떤 센서가 거리에 따라 이런 전압을 출력한다고 해보자.

```text
센서
거리 가까움 → 0.5 V
거리 중간   → 1.7 V
거리 멀음   → 2.8 V
```

MCU의 CPU는 이 전압을 그대로 계산하기 어렵기 때문에 ADC가 중간에서 숫자로 변환해.

```text
센서
 │
 │ 1.7 V ← 아날로그 신호
 ▼
┌───────┐
│  ADC  │  ← 전압을 숫자로 변환
└───┬───┘
    │
    │ 2109 ← 디지털 값
    ▼
 CPU Core 🧠
```

예를 들어 **12-bit ADC**이고 측정 범위가 `0 ~ 3.3 V`라면, 12비트로 표현할 수 있는 값은

$$
2^{12}=4096
$$

이므로 대략

```text
0 V   →    0
1.65V → 2048
3.3 V → 4095
```

가 돼.

그래서 ADC 값이 `2048`이 들어왔다면 CPU는 계산해서 **"약 1.65V가 들어왔구나"**라고 알 수 있어.

$$
V \approx \frac{2048}{4095}\times3.3
\approx1.65V
$$

### GPIO랑은 뭐가 다르냐면

이 차이가 중요해.

```text
일반 Digital GPIO

0 V ─────→ LOW  → 0
3.3 V ───→ HIGH → 1

        딱 0/1 위주
```

반면 ADC는:

```text
ADC

0.0 V ──→ 0
0.5 V ──→ 620
1.0 V ──→ 1241
1.7 V ──→ 2109
2.5 V ──→ 3102
3.3 V ──→ 4095

        전압의 '정도'를 측정
```

그래서 **가변저항, 아날로그 조이스틱, 압력센서, 온도센서처럼 연속적인 전압을 출력하는 장치**를 읽을 때 ADC를 많이 사용해.

지금까지 배운 MCU 구조에 넣으면:

```text
        MCU
┌───────────────────────┐
│                       │
│ 센서 → ADC → CPU Core │
│                │      │
│               ALU     │
│                       │
│ CPU → GPIO → LED      │
│                       │
│ Flash / SRAM          │
└───────────────────────┘
```

한마디로 **ADC = 센서가 보내는 전압을 CPU가 계산할 수 있는 숫자로 번역해주는 통역사**라고 기억하면 돼.
