### 💡 CPU Core (중앙처리장치 코어)란?

CPU 코어는 마이크로컨트롤러(MCU)의 '두뇌'에 해당하는 핵심 부품으로, 명령어의 해석과 연산, 데이터 처리 및 전체 시스템 제어를 담당합니다.

웹페이지에 나와 있는 5가지 주요 구성 요소는 다음과 같습니다:

* **ALU (산술논리장치, Arithmetic Logic Unit):**
    * 덧셈, 뺄셈 등의 **산술 연산**과 AND, OR 같은 **논리 연산**을 실제로 수행하는 회로입니다.


* **Control Unit (제어 장치):**
    * 메모리에서 명령어를 읽어와 해독하고, 컴퓨터의 다른 장치들에게 신호를 보내 **작업 순서를 지휘하고 통제**합니다.


* **Registers (레지스터):**
    * CPU 내부에서 연산에 필요한 데이터나 명령어를 **아주 빠른 속도로 임시 저장**하는 극소 용량의 고속 기억장치입니다.


* **Program Counter (프로그램 카운터):**
    * 다음에 실행해야 할 **명령어의 주소**를 기억하고 있는 특수 목적의 레지스터입니다.


* **Stack Pointer (스택 포인터):**
    * 메모리의 스택(Stack) 영역에서 데이터(함수 호출 시 돌아올 주소나 임시 변수 등)가 저장되고 있는 현재 위치(주소)를 가리키는 레지스터입니다.
