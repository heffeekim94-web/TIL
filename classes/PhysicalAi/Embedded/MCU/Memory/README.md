
### 💡 Memory (메모리)란?

마이크로컨트롤러(MCU)에서 프로그램 코드와 데이터를 저장하는 공간입니다. 역할과 특성에 따라 여러 종류의 메모리로 나뉩니다.

웹페이지에 나와 있는 5가지 주요 메모리 구성 요소는 다음과 같습니다:

**Flash (Program) (플래시 메모리):**
* 전원이 꺼져도 데이터가 지워지지 않는 **비휘발성 메모리**입니다. 작성한 프로그램 코드(펌웨어)가 영구적으로 저장되는 공간입니다.


**SRAM (Data) (정적 램):**
* 전원이 꺼지면 데이터가 사라지는 **휘발성 메모리**입니다. 프로그램이 실행되는 동안 필요한 변수나 데이터 값을 빠르게 읽고 쓸 때 사용합니다.


**EEPROM:**
* 플래시와 같이 전원이 꺼져도 유지되는 비휘발성 메모리이지만, **바이트 단위로 데이터를 수정·저장**할 수 있습니다. 주로 기기의 설정 값이나 사용자의 변경 데이터 등을 저장하는 데 쓰입니다.

**ROM / Bootloader (롬 / 부트로더):**
* 읽기 전용 메모리(ROM)로, MCU가 처음 켜졌을 때 실행되는 초기화 코드나 칩 구동에 필수적인 **부트로더**가 안전하게 담겨 있습니다.

**Cache (캐시):**
* CPU와 상대적으로 속도가 느린 메인 메모리(Flash/RAM) 사이의 **속도 차이를 줄이기 위해** 사용하는 초고속 임시 메모리입니다. 자주 쓰는 데이터를 미리 담아두어 처리 속도를 높입니다.
