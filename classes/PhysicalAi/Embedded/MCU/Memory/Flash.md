## Flash
- MCU에서 프로그램을 저장해 두는 장기 저장공간
- 전원을 꺼도 내용이 사라지지 않는다

<br>

구조:
```MCU
│
├─ CPU Core 🧠  → 프로그램을 실행
│   ├─ ALU      → 계산
│   └─ Register → 아주 잠깐 데이터 보관
│
├─ Flash 💾     → 프로그램 저장 ★
│
├─ SRAM         → 실행 중 필요한 데이터 저장
│
└─ GPIO         → 외부 장치와 0/1 신호 주고받음
```

<br>

차이점:
|        | Flash      | SRAM        |
| ------ | ---------- | ----------- |
| 역할     | 프로그램 보관    | 실행 중 데이터 보관 |
| 전원을 끄면 | **남아 있음**  | **사라짐**     |
| 예      | 작성한 펌웨어 코드 | 계산 중인 변수    |

<br>

전원을 끄면:
```
PC에서 코드 작성
      ↓
MCU에 Upload
      ↓
   [ Flash ]
   프로그램 저장
      ↓
전원 OFF ❌
      ↓
전원 ON ⚡
      ↓
Flash에 프로그램이 그대로 있음
      ↓
CPU Core가 프로그램 실행
```

<br>

저장 가능 여부 정보:
- `Flash 512 KB`, `Flash 1 MB`
