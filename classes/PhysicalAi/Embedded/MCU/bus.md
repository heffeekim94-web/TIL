## AHB/APB
- MCU 내부에서 CPU, 메모리, 주변장치들을 서로 연결해 주는 통신 통로(Bus)
```
             MCU 내부

       ┌──────────────┐
       │   CPU Core   │
       └──────┬───────┘
              │
           AHB Bus
      ════════╪══════════
              │
       ┌──────┴───────┐
       │   SRAM/Flash │
       └──────────────┘
              │
        AHB → APB Bridge
              │
           APB Bus
      ────────┼──────────
        │     │      │
       GPIO  UART   I2C
              │
             SPI
```

### AHB
- AHB = Advanced High-performance Bus

### APB
- APB = Advanced Peripheral Bus


| 구분     | AHB             | APB                 |
| ------ | --------------- | ------------------- |
| 목적     | 빠른 데이터 전송       | 주변장치 제어             |
| 속도/대역폭 | 높음              | 상대적으로 낮음            |
| 구조     | 복잡              | 단순                  |
| 주로 연결  | CPU, RAM, DMA 등 | GPIO, UART, Timer 등 |
| 비유     | 고속도로            | 동네 도로               |

---
### 💡 Bus System (버스 시스템)이란?

MCU 내부의 구성 요소들(CPU, 메모리, 주변장치 등)이 서로 데이터를 주고받을 수 있도록 연결해 주는 '데이터 통로(도로)'입니다.

웹페이지에 나와 있는 주요 버스 시스템 구성 요소는 다음과 같습니다:

**Address Bus (주소 버스):**
* CPU가 데이터나 명령어를 읽고 쓰기 위해 **"어느 위치(주소)에 접근할 것인지"** 그 위치 정보를 전달하는 단방향 통로입니다. 주소 버스의 폭(비트 수)에 따라 CPU가 접근할 수 있는 최대 메모리 용량이 결정됩니다.


**Data Bus (데이터 버스):**
* 실제로 **처리할 데이터나 명령어**가 오가는 양방향 통로입니다. 32비트 MCU라고 하면 보통 데이터 버스의 폭이 32비트라는 뜻으로, 한 번에 32비트씩 데이터를 전송할 수 있습니다.


**Control Bus (제어 버스):**
* 현재 수행하려는 작업이 **'읽기(Read)'인지 '쓰기(Write)'인지**, 그리고 장치들의 동작 타이밍을 조절하는 제어 신호를 전달하는 통로입니다.


**AHB / APB:**
* 현대 마이크로컨트롤러(특히 ARM 기반)에서 널리 쓰이는 대표적인 **온칩 버스 표준(AMBA)** 구조입니다.
* **AHB (Advanced High-performance Bus):** CPU, 메모리, 고속 통신 인터페이스처럼 **빠른 속도가 필요한 장치**들을 연결합니다.
* **APB (Advanced Peripheral Bus):** 타이머, GPIO, UART 등 **속도가 상대적으로 덜 중요한 저속 주변장치**들을 연결하여 효율적으로 전송을 관리합니다.
