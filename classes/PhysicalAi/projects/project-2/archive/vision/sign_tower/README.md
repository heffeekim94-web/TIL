# 신호등 (sign tower) OpenCR 펌웨어 — 복사본

Project2_Turtle_Ninja 미션 신호등용. 원본은 노트북 `~/pa-opencr-build/sketches/sign_tower_rc/sign_tower_rc.ino` (빌드 · 업로드는 그 폴더에서). 여기는 보관용 복사본 (2026-11-16 판).

- 보드: OpenCR + ROBOTIS RC-100 리모컨 (수신기 = OpenCR UART 포트, Serial2)
- 릴레이: 핀 5 빨강 · 6 노랑 · 7 초록 (LOW = 켜짐)

## 리모컨

| 버튼 | 동작 |
|---|---|
| 6 → 1 · 2 · 3 · 4 → 6 | 퍽 구성 입력 (빨강 직육면체 · 빨강 원기둥 · 초록 직육면체 · 초록 원기둥, 누른 횟수 = 개수). 빨강 빠르게 2번 = 저장 (전원 꺼도 남음), 빨강 2초 = 실패 |
| 5 (입력 중) | 처음부터 다시 입력 |
| D | 저장된 구성 확인 (1 → 4 순서로 개수만큼 0.5초 깜빡, 종류 사이 노란불) |
| U | 구성에 맞는 mission v5 신호를 랜덤으로 → 12번 (1초 켜짐 + 1초 꺼짐) + 3초 꺼짐 무한 반복. 다시 누르면 새 랜덤 |
| R | 마지막 세트 무한 반복 (전원 꺼도 기억) |
| L | 모두 끄기 (입력 중이어도) |
