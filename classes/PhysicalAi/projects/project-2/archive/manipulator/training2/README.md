# 학습2 — 무작위로 찬 적재함에서 퍽 넣기 · 빼기 · 주사위 칸 놓기 (무충돌)

혁무님 하드코딩 경로 (`config/arm_paths.yaml`) 를 시뮬 강화학습으로 대신한다.
실물 경로는 칸마다 "그때 찬 칸" 상태 하나로만 기록돼 있고, 그보다 더 찬 상태는 실물로 해 본 적이 없다.
지금 규칙 (`rack_cells.yaml rack_constraints`) 은 무작위 시작의 17 % 를 막고, 막지 않는 경우에도 부딪히는 경로가 있다.

- 기준 커밋: 팀 저장소 `feat/mission-system` 64eafaf
- 로봇: `../robot_usd` (혁무님 2026-11-10 xacro → `convert_to_archive.py`)
- Isaac Lab 6.2, rsl_rl 5 PPO (팀 `sim/robot_sim/rl` 과 같은 형식)

## 과제

에피소드마다 아래 순서로 진행한다.

1. **HOME** (`control.yaml poses.home`) 에서 출발한다.
2. 퍽을 쥔다.
3. 옮겨 놓는다.
4. 다시 HOME 으로 돌아온다.

| 과제 | 처음 퍽 자리 | 놓을 자리 |
|---|---|---|
| store | 박스 윗면 주사위 칸 | 빈 적재함 칸 |
| retrieve | 적재함 칸 | 박스 윗면 주사위 칸 |

- 나머지 칸은 무작위로 0 ~ 11 개 찬다. 처음에는 최대 3 개로 시작한다.
- 최근 400 에피소드 성공률이 60 % 를 넘으면 최대 개수를 1 개 늘린다 (커리큘럼).
- 주사위 칸은 가까운 줄과 가운데 줄 6 개를 쓴다.
  - 먼 줄은 실물도 30° 다시 쥐기가 필요해서 지금은 뺐다 (`cfg.TaskCfg.dice_rows`).

## 보상 (`cfg.RewardCfg`)

| 항목 | 값 | 비고 |

| 5 mm 안으로 다가감 | 0 → −0.2 | |

| 쥔 퍽을 떨어뜨림 | −5, 에피소드 끝 | |
| 넣을 · 뺄 칸 컵 벽 스침 | −0.05 / 스텝 | **사용자와 정할 값** |
| 쥠 (그리퍼 힘 + 손가락이 퍽 폭에서 멈춤 + 손 안 퍽) | +1 (한 번) | |
| 바르게 놓음 | +10 | 그때까지 충돌 0 일 때만 |
| HOME 으로 돌아옴 | +2 | 충돌 0 일 때만 |
| 손 → 퍽 · 퍽 → 목표 · 관절 → HOME 거리 줄임 | 퍼텐셜 차 | |

## 충돌 판정

### 왜 직접 재나

USD 로 바꾸면 고정 관절로 붙은 부품이 몸체 하나 (`base_footprint`) 로 합쳐진다. 적재함 · 프로파일 기둥 · 받침 · 차체가 모두 여기에 들어간다.
그래서 PhysX 접촉만으로는 어느 부품에 닿았는지 모른다. 대신 `geometry.py` 가 URDF 링크 단위로 직접 잰다.

- 팔: 표면 점 9,297 개 (5 mm 간격)
- 몸체: 부품 상자 117 개. 칸마다 컵 벽 8 개 (URDF `rack_cell_*_collision_*`) 포함

### 재는 것

| 무엇 ↔ 무엇 | 방법 |
|---|---|
| 팔 ↔ 적재된 퍽 | 점 ↔ 상자 거리 |
| 팔 ↔ 몸체 부품 (프로파일 기둥 · 차체 · 적재함 · 라이다) | 점 ↔ 상자 거리 |
| 팔 ↔ 박스 | 점 ↔ 상자 거리 |
| 작업 퍽 ↔ 적재된 퍽 | 점 ↔ 상자 거리 |
| 작업 퍽 ↔ 몸체 부품 | 점 ↔ 상자 거리. 제 칸 컵 · 적재함 바닥판은 뺌 |
| 손 쪽 (link5 · 손목 · 손가락) ↔ link2 · link3 | PhysX 필터 접촉 힘 > 0.5 N |

### 예외 · 확인한 것 (2026-11-10)

- **그리퍼 받침**은 앉는 자리라서, HOME 근처는 아예 빼고 그 밖에서는 1 mm 넘게 파고들 때만 충돌로 친다.
- **wrist ↔ link2** 는 충돌 메시가 HOME 에서 원래 겹친다 (약 36 N). 팀 `ninja_turtle.srdf` 도 reason="Default" 로 꺼 둔 쌍이라 HOME 근처만 뺀다.
- **적재 퍽 밀림**은 컵 밖으로 밀려날 때 (10 mm · 20°) 만 친다.
  - 팔이 받침에서 빠질 때 몸체가 0.1° 흔들리면 17 g 퍽이 컵 안에서 13° 기운다.
  - 이때 퍽에 닿은 건 적재함뿐이었다 (팔은 16 mm 밖, 접촉 센서로 확인).
- PhysX 충돌 껍질과 시각 메시는 1 mm 안에서 같다 (경유점 up7 에서 링크별로 비교).

| 항목 | 값 | 출처 |

| 그리퍼 힘 | 빈손 0.05 N, 퍽 쥠 3.5 N | 쥠 판정에 씀 (실물 = 전류) |

| 적재 칸 퍽 | 고정 장애물 (kinematic), 매 스텝 로봇 몸체를 따라감 | 동적으로 두면 팔이 받침에서 떠오를 때 몸체가 튀어 17 g 퍽이 날아감 (env 여러 개일 때 최대 54 mm, 팔은 8 mm 밖) |

| 관절 최고 속도 | 0.7 rad/s (40 °/s) | 실물 빈 공간 최고 |

## 파일

| 파일 | 내용 |
|---|---|
| `cfg.py` | 장면 · 과제 · 보상 · PPO |
| `env.py` | DirectRLEnv: 리셋 (무작위 점유) · 행동 · 충돌 · 쥠 · 보상 · 관측 (정책 80, critic +11) |
| `geometry.py` | URDF → 팔 표면 점 · 몸체 부품 상자 · 손가락 패드, GPU 점 ↔ 상자 거리 |
| `scenarios.py` | 평가용 고정 시나리오 (seed 같으면 같은 목록 → 팀원과 비교) |
| `train.py` | 학습 → `logs/<시각>_<이름>/` (model_*.pt · TensorBoard · cfg.json) |
| `play.py` | 평가: 충돌 · 떨어뜨림 · 최소 거리 · 찬 칸 수별 성공률 → eval_*.json (+ GIF) |
| `replay_check.py` | 환경 검증: 실물 기록 경로 (기본 = 기록 때 찬 칸) 를 처짐 보정 빼고 재생해 판정을 확인 |
| `sag.py` | 팀 처짐 모델: 실물 명령값 ↔ 실제 자세 |
| `run_tmux.sh` | tmux 세션 `train2` 에서 학습 |
| `viz.py` | GIF 카메라 |

## 실행

```bash
cd archive/manipulator/training2
PY="env -u PYTHONPATH PYTHONDONTWRITEBYTECODE=1 OMNI_KIT_ACCEPT_EULA=YES $HOME/pa-course/IsaacLab-6.2/.venv/bin/python"
bash run_tmux.sh t1                                   # 학습 (env 256 · 3000 iter ≈ 9 시간)
tmux attach -t train2                                 # 보기 (빠져나오기 Ctrl-b 다음 d)
$PY play.py --checkpoint logs/<실행>/model_3000.pt     # 평가 1000 에피소드
$PY replay_check.py --path retrieve_S5                # 환경 검증 (기록 때 찬 칸 그대로)
```

## 합격 기준 (2026-11-10 정함)

고정 시나리오 (`scenarios.py`, 찬 칸 0 ~ 11 개 고르게) 에서 아래를 모두 만족해야 한다.

1. 충돌 0 번
2. 떨어뜨림 0 번
3. 최소 거리가 여유 이상. 기준값은 실물 오차를 보고 정한다.

통과하면 관절 ±2° 오차를 넣어 다시 평가하고 (팀 `pose_safety` 와 같은 기준), 그다음 실물로 간다.

## 아직 안 된 것 · 확인할 것

### 실물 경로 재생 (해결, 2026-11-10)

`arm_paths.yaml` 은 실물 처짐을 보정한 명령값이라 그대로 주면 시뮬 손이 퍽 위에서 닫혔다.
`sag.py` (팀 `arm_kinematics.cpp` 처짐 모델) 로 실제 자세로 되돌려 재생한다.
쥐는 점도 팀 모델 손끝 `tip5` 를 손목 좌표로 옮겨 쓴다 (`env.TIP_WRIST`).

- 결과: `retrieve_S5` 를 기록 때처럼 9 칸이 찬 상태로 재생 → 쥐고 꺼내 옮김, 충돌 0.
- 실물 경로는 옆 칸이 빈 상태로 기록된 것이 많다. 그리퍼를 끝까지 벌리는 경로는 옆 칸이 차면 손가락이 옆 퍽에 닿는다 (팀 `grasp_select` 는 벌림 폭을 줄임).

### 손이 기운 자세에서 그리퍼를 열면 퍽이 손가락 사이에 걸림

공중 시험에서 퍽이 바로 떨어지지 않았다. 컵이나 박스 바닥에 닿은 채 놓을 때도 그런지 학습 결과로 확인해야 한다.
