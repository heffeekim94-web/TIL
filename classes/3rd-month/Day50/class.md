rom과 ram의 차이 
rom - 영구 저장소 
sd, ssd, hd
전원이 차단 돼도 영구적으로 저장 되는 장소 
ram - 임시 저장소 
전원이 차단되면 없어짐
rom보다 빠름 
게임에 ram이 높은게 필요한 이유는 속도 때문 

로봇을 처리해야 하는 정보가 많을수록 ram도 많이 필요하다 
ram은 gpu에만 달려있다 
컴퓨터는 cpu, graphic card, ssd 마다 각각 사야 하는 이유가 
한 반도체에 모든 기능을 담기에는 물리적인 한계가 있기 때문 
메인 보드 - 각 부품을 전선으로 연결하는 공간 
서로 교환되는 정보가 많을수록 발열이 많이 되고 
ram. vRam을 생각해보면 컴퓨터에 2가지 ram이 있다 
hdm - vram 반도체를 블록을 쌓듯이 쌓아 놓은 기술 
jetson - 메인보드의 전선 연결 공간 없이 직접 vram과 ram을 연결하는 것.
저전력 때문에 저성능이 될 수 있음 
이런 반도체를 한 공간에 꽉 잘 채우는 회사가 apple이다
삼성이랑 딜을 안하는 이유 ratical한 것을 꽈곽 채워서 
ai 칩을 a1 ,b1을 만들었는데 각각 더해서 mUltra를 만듬
