## 문제점
- 팀원들이 프로젝트 진도에 관하여 플랜과 구성에 대한 내용을 상의하는데 도저히 알아듣지 못하겠다. 라벨링은 뭐고 노드는 어떻게 뭘 해야 하며.. 갑자기 위기를 느꼈다. 이러다 아무런 도움이 되지 못한채로 끝나는건 아닐까 우려스러웠다.




<br>

## 해결 방법

- 우선은 들렸던 대체적인 부분들을 해석해달라고 ai에게 요청했고 공부했다. 
- 우선 파일에 들어있는 모든 구성들을 이해하고자 파일 하나하나 ai에게 설명해달라고 했다. 


<br>

## 결과

- 이제는 들린다. 팀원들의 주 고민 거리와 우리가 하면 되는 부분들을 조금더 자세히 알아듣게 되었다. 맘이 놓이고 이렇게만 계속 유지해오면 된다라는 믿음이 생겼다. 
- 지나가다 다른 멤버가 다른 학생에게 내가 숙지했던 내용을 그대로 설명해주는 것을 들었다. 그건 내가 직접 숙지해서 알게 되었는데 저 사람은 고수인데도 설명을 듣고 있구나. 그럼 설명을 해주는 분도 자습으로 알게 되었겠지. 그럼 나도 이제 이렇게만 잘 공부하면 알 수 있겠구나 확신이 선다. 



<br>
