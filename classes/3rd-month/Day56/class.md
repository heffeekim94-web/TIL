# 10/26 배운 것: CVAT · 클래스 설계 · 학습 환경

(이날은 수업 노트가 없어 작업하면서 새로 배운 것을 정리)

- **CVAT (라벨링 도구)**
  - Docker로 로컬 설치(v2.80.0)하고, 팀장님 서버(10.2.12.120:8080)에서 organization에 합류해 팀 task를 같이 라벨링
  - 구조: project → task(영상·사진 묶음) → job(실제 라벨링 단위). 라벨 이름과 순서가 곧 YOLO 클래스 번호
  - 내보내기: YOLO 1.1 형식은 `obj_train_data/`에 사진·txt, `obj.names`에 클래스 순서. **Save images를 켜야 사진이 같이 나옴**
  - 서버가 팀장님 노트북이라 노트북이 꺼지면 접속 불가 → 작업 끝에 바로 백업
- **클래스 설계**
  - AprilTag는 YOLO로 찾지 않고 전용 검출기로 처리: 번호(ID)와 3D 자세까지 계산해 주기 때문. YOLO는 퍽 자체에 집중
  - 팀 6클래스(red/green × cylinder/box, barcode, traffic_light)로 맞춰야 팀 데이터·모델을 같이 쓸 수 있음
  - 신호등 색은 YOLO 클래스로 나누지 않고, 박스 안을 HSV로 판정: V(밝기)로 켜짐/꺼짐, H(색상)로 빨강·노랑·초록
- **점수가 0일 때 원인 찾기**
  - 라벨 박스를 잘라 train과 val/test를 나란히 비교해 보니, 학습셋에 상자 바코드 사진 자체가 없었음 → 숫자만 보지 말고 실제 라벨 사진을 확인
- **학습 환경 분리**
  - 레포는 건드리지 않고 archive에 팀 전달본을 풀고 그 안에 venv를 만듦. 스크립트가 경로를 자기 위치 기준으로 계산하면 어디서든 실행 가능
  - `prepare_data.py --real_repeat 6`: 실제 사진을 반복해 2단계 학습에서 실제 비중을 약 18%로 맞춤
