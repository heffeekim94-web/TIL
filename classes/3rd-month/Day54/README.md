## 문제점
- 터미널과 에디터에서 노트북이 한 번씩 실행돼 학습이 두 개 돌고 있었음
- sim val mAP50이 20 epoch 만에 0.98로 수렴하는데 실물은 0.243 → 학습이 제대로 되는 건지 의심
- 입력 크기 960을 검토만 하고 실험은 1280으로만 돌림




<br>

## 해결 방법

- 나중에 시작한 에디터 쪽 커널을 kill, 학습 중에는 에디터에서 노트북 안 열기
- 합성 500장이 생성 1회분에서 나와 train·val·test 분포가 같다는 것 확인 → sim val로는 비교 결론을 낼 수 없음
- 실물을 val(모델 선택) / test(최종 점수)로 나누고, 실물 사진을 학습에 섞기로 함


<br>
