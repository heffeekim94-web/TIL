## 뜻

YOLO 같은 객체 탐지 모델을 **실제로 쓸 만한 수준**까지 학습시키려면 학습용 이미지를 **대략 3만 장 정도는 모아서 라벨링해야 한다**는 현업의 경험칙이에요. 정해진 규칙은 아니고, "수백 장으로는 부족하다"는 감을 주려는 숫자에 가깝습니다.

## 왜 그렇게 많이 필요한가

1. **일반화 때문이에요.** 모델은 본 적 없는 상황에 약해요. 같은 물체라도 조명(낮/밤/역광), 각도, 거리, 가림(occlusion), 배경, 카메라 기종이 바뀌면 못 잡는 경우가 많아요. 이런 조합을 골고루 보여주려면 장수가 많아질 수밖에 없어요.
2. **과적합을 막기 위해서예요.** 데이터가 적으면 학습셋은 외워서 mAP가 높게 나와도 실제 현장에서는 성능이 떨어져요.
3. **클래스가 여러 개일 때 그래요.** 클래스마다 충분한 예시가 필요해서 클래스 수에 비례해 늘어나요.
4. **train/val/test로 나누기 때문이에요.** 3만 장을 다 학습에 쓰는 게 아니라 일부는 검증용과 테스트용으로 떼어둬요.

참고로 Ultralytics(YOLO 개발사) 공식 권장은 **클래스당 이미지 1,500장 이상, 라벨된 객체(instance) 10,000개 이상**이에요. 클래스가 몇 개만 돼도 금방 수만 장 규모가 됩니다.

## 주의할 점

- **"찍는다"가 핵심이에요.** 영상에서 연속 프레임을 잘라 3만 장을 만들면 거의 같은 사진 3만 장이라 효과가 적어요. 장수보다 **다양성**이 중요해요.
- **사전학습 모델로 파인튜닝하면 훨씬 적게도 돼요.** 보통 `yolov8n.pt` 같은 COCO 가중치에서 시작하는데, 간단한 과제라면 수백~수천 장으로도 데모 수준은 나와요. 3만 장은 실서비스나 높은 정확도를 목표로 할 때의 기준이에요.
- **데이터 증강(augmentation)으로 일부 보완할 수 있어요.** YOLO는 mosaic, flip, HSV 변환 등을 기본으로 해주지만, 실제 다양한 환경에서 찍은 데이터를 대체하지는 못해요.

한 줄로 요약하면, **현장에서 제대로 동작하는 탐지기를 만들려면 다양한 조건에서 찍은 데이터가 수만 장 단위로 필요하다**는 뜻이에요.

## 전체 흐름

```
① 데이터 수집 → ② 라벨링 → ③ 데이터셋 구성 → ④ 학습 → ⑤ 평가 → ⑥ 추론(사용)
```

요즘은 **Ultralytics** 라이브러리(YOLOv8/v11)로 하는 게 표준이에요.

```bash
pip install ultralytics
```

### 0. 일단 돌려보기 (학습 없이)

COCO 데이터(사람, 차, 개 등 80개 클래스)로 이미 학습된 모델이 있어서 바로 써볼 수 있어요.

```python
from ultralytics import YOLO

model = YOLO("yolov8n.pt")          # 사전학습 모델 (n < s < m < l < x 순으로 크고 정확함)
results = model("bus.jpg")          # 이미지, 영상, 웹캠(0) 다 가능
results[0].show()                   # 박스 그려진 결과 보기
```

### 1~2. 데이터 수집과 라벨링

내 물체(예: 불량품, 헬멧)를 찾게 하려면 직접 사진을 모아서 **박스를 그려야** 해요. 앞에서 말한 "3만 장"이 이 단계 얘기예요.

- 도구: **Roboflow**, **CVAT**, **Label Studio** 등
- YOLO 라벨 형식은 이미지마다 `.txt` 파일 하나이고, 한 줄에 박스 하나예요.

```
# 클래스번호  중심x  중심y  너비  높이   (모두 0~1로 정규화)
0 0.512 0.430 0.210 0.380
1 0.150 0.700 0.080 0.120
```

### 3. 데이터셋 구성

```
dataset/
├── images/
│   ├── train/   (약 70~80%)
│   └── val/     (약 20%)
└── labels/
    ├── train/   ← 이미지와 파일명 같게 (a.jpg ↔ a.txt)
    └── val/
```

`data.yaml` 파일을 만들어요.

```yaml
path: ./dataset
train: images/train
val: images/val
names:
  0: helmet
  1: head
```

### 4. 학습

```python
model = YOLO("yolov8n.pt")   # 사전학습 가중치에서 시작 (파인튜닝)
model.train(data="data.yaml", epochs=100, imgsz=640, batch=16)
```

결과는 `runs/detect/train/` 폴더에 저장되고, `weights/best.pt`가 최종 모델이에요.

### 5. 평가

```python
metrics = model.val()
print(metrics.box.map50)   # mAP@0.5: 높을수록 좋음
```

`runs/detect/train/` 안의 `results.png`(loss 곡선)와 `confusion_matrix.png`를 같이 보면 돼요.

### 6. 사용

```python
model = YOLO("runs/detect/train/weights/best.pt")
results = model("test.jpg", conf=0.5)   # 신뢰도 0.5 이상만
for box in results[0].boxes:
    print(box.cls, box.conf, box.xyxy)  # 클래스, 신뢰도, 좌표
```

## 원리 (짧게)

**YOLO = You Only Look Once.** 이미지를 **한 번만** 신경망에 통과시켜 "어디에(박스) 무엇이(클래스) 있는지"를 동시에 예측해요. 예전 방식(R-CNN 계열)은 후보 영역을 먼저 뽑고 하나씩 분류해서 느렸는데, YOLO는 한 번에 처리해서 **실시간**이 가능해요.

1. 이미지를 격자(grid)로 나누고, 각 칸이 박스 좌표, 객체가 있을 확률, 클래스를 예측해요.
2. 박스가 겹쳐서 많이 나오면 **NMS(Non-Maximum Suppression)**로 가장 확실한 것만 남겨요.

수업에서 특정 버전(v5, v8 등)이나 특정 단계를 다뤘다면 알려주세요. 그 부분을 더 자세히 설명할게요.

## 라벨링이란

**모델이 배울 수 있도록 데이터에 정답을 표시해 주는 작업**이에요. 어노테이션(annotation)이라고도 해요.

모델은 사진만 봐서는 뭐가 뭔지 몰라요. 그래서 사람이 먼저 "이 사진의 여기에 헬멧이 있어"라고 표시해 줘야 해요. 이렇게 정답이 붙은 데이터를 수천, 수만 장 보면서 모델이 패턴을 배워요.

```
사진만 있음        →  모델: "???"
사진 + 정답 표시   →  모델: "아, 이렇게 생긴 게 헬멧이구나"
```

시험 공부에 비유하면, 문제집(사진)에 **답지(라벨)**를 만들어 주는 거예요. 답지가 없으면 채점도 학습도 못 해요.

## YOLO(객체 탐지)에서의 라벨링

이미지 안의 물체마다 **박스를 그리고 이름을 붙여요.**

```
┌─────────────────────────┐
│   ┌──────┐              │
│   │helmet│   ┌────┐     │
│   │      │   │head│     │
│   └──────┘   └────┘     │
└─────────────────────────┘
```

라벨링 도구에서 마우스로 박스를 그리면, 도구가 자동으로 아래 같은 `.txt` 파일을 만들어 줘요.

```
0 0.30 0.35 0.20 0.30    ← helmet(0번)의 중심 위치와 크기
1 0.62 0.38 0.12 0.18    ← head(1번)의 중심 위치와 크기
```

## 작업마다 라벨 형태가 달라요

| 작업 | 라벨링 방법 | 예시 |
|---|---|---|
| 분류 (Classification) | 사진 전체에 이름 하나 | "이 사진은 고양이" |
| **객체 탐지 (Detection)** | **물체마다 박스와 이름** | **YOLO 기본** |
| 분할 (Segmentation) | 물체 윤곽을 따라 다각형 | 픽셀 단위로 영역 표시 |
| 포즈 (Pose) | 관절 위치에 점 찍기 | 어깨, 팔꿈치, 무릎 |

## 왜 중요하고 힘든가

- **시간이 제일 많이 드는 단계예요.** 3만 장이면 박스를 수만~수십만 개 그려야 해서, 현업에서는 외주를 주거나 라벨링 전문 인력을 쓰기도 해요.
- **품질이 성능을 결정해요.** 박스를 대충 그리거나 빠뜨리거나 이름을 잘못 붙이면 모델도 그대로 잘못 배워요. "Garbage in, garbage out."
- **기준을 통일해야 해요.** "반쯤 가려진 물체도 표시하나?", "박스를 어디까지 딱 맞추나?" 같은 규칙을 정해 두지 않으면 사람마다 다르게 라벨링해서 모델이 헷갈려요.

## 주요 도구

- **Roboflow**: 웹 기반이라 초보자에게 가장 쉽고, YOLO 형식으로 바로 내보낼 수 있어요.
- **CVAT**: 무료 오픈소스이고 기능이 많아요.
- **Label Studio**: 이미지 외에 텍스트, 음성 라벨링도 돼요.
- **LabelImg**: 설치형이고 단순해요. 지금은 업데이트가 멈췄어요.

시간을 줄이려면 **자동 라벨링**도 많이 써요. 학습된 모델로 먼저 박스를 그려 놓고, 사람은 틀린 것만 고치는 방식이에요.

## 1. Roboflow

**웹 브라우저에서 쓰는 올인원 플랫폼**이에요. 라벨링만 하는 게 아니라 데이터 관리부터 학습, 배포까지 다 돼요.

**특징**
- 설치 없이 사이트(roboflow.com)에 가입하면 바로 쓸 수 있어요.
- 라벨링이 끝나면 **YOLO 형식으로 바로 내보낼 수 있어요.** train/val/test 분할과 `data.yaml`까지 자동으로 만들어 줘요.
- 증강(회전, 밝기 조절 등)과 리사이즈를 클릭 몇 번으로 적용할 수 있어요.
- **Roboflow Universe**에 다른 사람들이 공개한 데이터셋이 아주 많아서, 직접 라벨링하지 않고 받아 쓸 수도 있어요.
- AI 보조 라벨링 기능이 있어서 박스를 자동으로 제안해 줘요.

**단점**
- 무료 플랜은 프로젝트가 **공개(public)**로 올라가고 사용량 제한이 있어요. 회사 데이터나 민감한 데이터에는 부적합해요.
- 데이터가 외부 서버에 저장돼요.

**이럴 때 추천**: 수업 실습, 개인 프로젝트, 처음 YOLO를 해 볼 때

```python
# Roboflow에서 내보낸 데이터셋을 코드로 바로 받기
from roboflow import Roboflow
rf = Roboflow(api_key="내_API_키")
dataset = rf.workspace("내워크스페이스").project("프로젝트명").version(1).download("yolov8")
```

## 2. CVAT (Computer Vision Annotation Tool)

**인텔이 만든 오픈소스 라벨링 도구**예요. 지금은 CVAT.ai라는 회사가 이어서 개발하고 있어요. 전문 라벨링 작업에 많이 써요.

**특징**
- 무료이고, **내 서버에 직접 설치(Docker)**할 수 있어서 데이터가 밖으로 나가지 않아요.
- 클라우드 버전(app.cvat.ai)도 있어서 설치 없이 써 볼 수도 있어요.
- 박스, 다각형, 점, 선, 3D 포인트 클라우드까지 거의 모든 라벨 형태를 지원해요.
- **영상 라벨링이 강력해요.** 첫 프레임과 마지막 프레임에만 박스를 그리면 중간 프레임을 자동으로 채워 줘요(interpolation).
- 여러 명이 작업을 나눠 하고, 검수자가 확인하는 **팀 협업 기능**이 좋아요.
- SAM 같은 AI 모델을 붙여서 클릭 한 번으로 윤곽을 따는 자동 라벨링도 돼요.

**단점**
- 기능이 많아서 처음엔 복잡하게 느껴져요.
- 직접 설치하려면 Docker 지식이 조금 필요해요.

**이럴 때 추천**: 회사 프로젝트, 팀 작업, 영상 데이터, 보안이 중요한 데이터

```bash
# 로컬 설치 (Docker 필요)
git clone https://github.com/cvat-ai/cvat
cd cvat
docker compose up -d
# 브라우저에서 localhost:8080 접속
```

## 3. Label Studio

**이미지 말고도 거의 모든 종류의 데이터를 라벨링할 수 있는 범용 도구**예요. HumanSignal이라는 회사가 만든 오픈소스예요.

**특징**
- 이미지, **텍스트, 음성, 영상, 시계열 데이터**까지 라벨링할 수 있어요.
  - 예: 문장 감정 분류, 개체명 표시, 음성 받아쓰기
- `pip`로 간단히 설치하고 브라우저에서 사용해요.
- 라벨링 화면을 설정(XML 템플릿)으로 자유롭게 바꿀 수 있어요.
- ML 백엔드를 연결해서 모델 예측을 미리 채워 넣는 자동 라벨링을 할 수 있어요.

**단점**
- 범용이다 보니 이미지 탐지만 놓고 보면 CVAT보다 기능이 덜 세밀해요.
- YOLO 형식으로 내보낼 수는 있지만, 폴더 구조는 직접 정리해야 할 때가 있어요.

**이럴 때 추천**: 이미지 외에 NLP나 음성 데이터도 다룰 때, 한 도구로 여러 작업을 할 때

```bash
pip install label-studio
label-studio start
# 브라우저에서 localhost:8080 접속
```

## 4. LabelImg

**박스 그리기만 하는 가장 단순한 데스크톱 프로그램**이에요. 예전 YOLO 튜토리얼에 거의 다 나왔던 고전 도구예요.

**특징**
- 설치가 간단하고 가벼워요. 인터넷 없이 내 컴퓨터에서만 돌아가요.
- 단축키(`W`: 박스 그리기, `D`: 다음 사진, `A`: 이전 사진)가 있어서 빠르게 작업할 수 있어요.
- 저장 형식을 **YOLO(.txt)**와 **Pascal VOC(.xml)** 중에서 고를 수 있어요.

**단점**
- **업데이트가 중단됐어요.** 지금은 Label Studio 쪽으로 흡수됐고, 최신 파이썬 버전에서는 설치 오류가 나기도 해요.
- 박스만 지원해요. 다각형이나 키포인트는 안 돼요.
- 협업, 자동 라벨링 기능이 없어요.

**이럴 때 추천**: 소량의 사진에 박스만 빨리 그리고 싶을 때. 새로 시작한다면 다른 도구가 더 나아요.

```bash
pip install labelImg
labelImg
```
