## 문제점
- Isaac Sim 6.1에서 fisheye 카메라로 렌더링하면 화면 모서리와 좌우 끝이 잘림 (주점에서 640px 밖이 비어 있음, IsaacSim#838 버그)
- 합성 데이터로만 학습한 모델을 실제 카메라에 돌리니 퍽이 아닌 물체를 퍽으로 잡는 오탐이 많음
- main에서 합성 데이터 코드(`yolo/dataset_gen`)가 지워져서 비전 작업 일부를 main에 못 넣음




<br>

## 해결 방법

- 렌더링 폭을 1280 → 1552로 넓히고 주점을 옮긴 뒤, 저장할 때 가운데 1280×720만 잘라냄 (상자 좌표도 같이 이동)
- 실측 K·D로 3D 위치를 투영해서 실제 상자 중심과 비교해 검증
- 오탐은 다음 날 영상을 저장해서 다시 분석하기로 함
- dataset_gen을 지운 이유는 팀에 확인하기로 함


<br>

## 결과

- 합성 사진 상자 중심 오차 평균 1.3 px, 최대 2.9 px (보정 없는 pinhole은 최대 57 px)
- 시험 학습 합성 검증셋 mAP50 0.969
- 가이드 퍽 픽셀 표 갱신: 유효 탐지 거리 1.2 m → 1.8 m 안팎
- Arducam 실측 30.5 fps (1280×720 MJPG)
