- 같은 학습을 더 오래 돌린다고 좋아지지 않는다. 툭 건드리기를 200번 더 (n1c) 돌렸더니 89% → 70% 로 오히려 나빠졌다
- 강화학습이 아무것도 안 하고 가만히 있는 걸 배우면, 다가가는 보상이 너무 작다는 뜻이다. 쉬운 것부터 시작하는 커리큘럼과 큰 다가가기 보상이 필요하다
- 시뮬레이션 리셋에서 손가락이 퍽 안에 겹쳐 생기면 물리가 밀어내면서 차체가 들린다. 실패 원인을 짐작으로 말하지 말고 시뮬에서 직접 재야 한다
- 덜컹의 원인을 "그리퍼가 퍽을 누른다" 고 짐작했는데 틀렸다. 재 보니 그리퍼는 아무것도 누르지 않았고 차체가 박스 쪽에 걸려 기운 채 있었다
- 센서가 이상하면 먼저 배선 · 장착을 의심한다. 초음파 문제는 전부 레일 +/− 반대, 녹슨 선, 몸체 · 카메라에 가린 센서, 좌우 바뀜이었다
- 라이다 (LDS-03) 는 한 바퀴 점 수가 매번 달라서 slam_toolbox 가 스캔을 버린다. 점 수를 고정해 주는 노드가 필요하다
- 와이파이에서 ROS 가 서로 못 찾으면 `ROS_STATIC_PEERS` 로 상대 IP 를 직접 알려 준다
- 지도를 모르는 정지 규칙은 벽에도 멈추고, 모든 움직임을 막으면 빠져나올 수도 없다. 지도 벽과 새 장애물을 구분해야 한다
