## 문제점
- 처음 만든 동작이 퍽을 이상하게 쥐어서 옆 퍽과 닿음 (혁무님 쥐는 방식을 반영 안 함)
- 팀 실물 경로를 시뮬에서 재생하니 퍽을 못 집음 (처짐 보정)
- 퍽 크기를 34.8 mm 로 잘못 씀 (실제 30 mm, 34.8 은 누운 퍽 높이)
- 주사위 이어서 놓기: 퍽이 튀고, 다음 칸으로 갈 때 J5 가 한계에 걸려 손가락이 옆 퍽 쪽을 향함
- 누운 퍽을 받침에서 눌러 세워도 손을 떼면 다시 넘어감
- 박스 먼 쪽 누운 퍽, 면이 35° 넘게 돈 먼 선 퍽은 팀 방식으로 못 집음 (무작위 배치 16개 중 6개만 끝까지 계획됨)



<br>

## 해결 방법

- 혁무님 방식 (grasp_select · regrasp_nodes · park_stand) 을 파이썬으로 옮겨서 그대로 따름
- 처짐 보정을 거꾸로 계산하는 `sag.py` 를 만들어 실제 자세로 바꿈
- 팀 일어서기 · 접기 경로를 관절 0.04 rad 씩 나눠 천천히, 다음 칸으로 갈 때 J5 방향 두 가지를 다 만들어 보고 맞는 쪽을 고름
- 받침 누르는 자리 −16 → −22 mm, 다시 쥐는 자리 +4 mm 로 바꿔 퍽이 바로 섬
- 못 집는 배치는 기록만 하고 따로 정하기로 함
