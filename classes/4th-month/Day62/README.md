## 문제점
- 신호등이 3초마다 색을 바꿔서 한 색을 고정해 시험할 수 없었음
- 리모컨 1번 상태에서 다른 버튼을 눌러도 바뀌지 않았고, 꺼지는 버튼이 없었음
- 업로드가 `Fail to open port` 로 실패
- Jetson 접속이 `Connection refused`, 접속 후에도 토픽이 안 보이고 뷰어 창이 까맣게 뜸
- Jetson 광각 엔진이 어느 모델로 만든 건지 알 수 없었음
- 끝무렵 광각 영상(`/wide_cam/image_raw`)이 안 들어와 탐지 결과가 안 나옴




<br>

## 해결 방법

- 시리얼 명령(r/y/g/o/a)으로 색을 고정하는 판 → RC-100 리모컨으로 고르는 판 (Serial2 수신기, `RC100` 라이브러리)
- 리모컨 값에서 새로 눌린 버튼 비트만 처리하고, 1·2·3·4·U 가 아닌 버튼은 끄기로
- 포트 이름 오타(`/dev/tyACM0` → `/dev/ttyACM0`) 수정, `CRC OK` · `[OK] Download` 로 성공 확인
- IP 를 잘못 받아 적어 다른 기기에 접속하고 있었음 (MAC 주소로 확인), ROS_DOMAIN_ID 17 을 맞추고 Jetson `~/.bashrc` 설정을 그대로 쓰는 실행 스크립트로 정리
- Jetson `wide_best.onnx` 와 노트북 최종 모델 ONNX 의 md5 를 비교
- 광각 영상 문제는 내일 확인 (드라이버 · 전송 설정)


<br>

## 결과

- 리모컨 펌웨어: 전원 시 소등, 1 = 3초 순환, 2/3/4 = 빨/노/초 고정, U = 랜덤 12번 깜빡, 그 외 = 끄기
- 신호등 인지 시험 통과
- wide_best = 최종 모델(real_ft_fixed33_1030) 확인: 960×960 평균 8.91 ms (팀원이 만든 544×960 은 5.96 ms)
- 노트북 원격 뷰어: 광각 영상 + 신호등 판정 + 칸 경계 · 밝기 점수
