## 문제점
- t1 (처음부터 배우기) 이 새벽 1210번에서 NaN 으로 멈춤, 성공 0
- r1 보정 학습이 기본 경로보다 나빠짐 (보상 −7 → −224)
- 꺼낸 퍽을 꺼낼 때 손 각도 그대로 주사위 자리에 놓음, 놓는 순서도 틀림
- 주사위 자리에 놓은 퍽이 넘어짐
- 팔이 갑자기 하늘로 솟음
- 팔을 크게 움직일 때 몸체가 들리면서 덜컹함
- 움직임이 느리고, 빠르게 하니 구간마다 뚝뚝 끊김
- 내 맘대로 정한 것 (퍽 사이 HOME 들르기 등) 때문에 시간을 버림
- 칸에 삐뚤게 들어간 퍽을 스테이션으로 가져가서 다시 쥐는 복구는 너무 느림



<br>

## 해결 방법

- 기본 경로 + 보정 학습 (residual) 으로 바꿈, NaN 이 나면 그 env 만 다시 시작
- 탐색 폭 0.1, 보정 0.05 배, 저역 필터 0.8, 그리퍼 보정 끔
- 꺼낸 뒤 몸체를 정면으로 돌리면서 J5 원점 → 자리 확인 → 내려놓기, 놓는 순서 (−줄, 칸)
- 먼 자리는 가까이 내려놓고 20–30° 기울인 손으로 다시 쥐어 살짝 들어 옮김
- 관절 각도 2π 이어 붙이기 (`unwrap_limits`)
- 멈추는 곳 사이 한 번의 가감속 (가속 5 → 나중에 3.7), 빈 공간 150°/s · 퍽 근처 62.5°/s
- 기울기 · 바퀴 뜸 감점, 안정 보상
- 헷갈리면 먼저 묻고, 두 번 안 되면 영상과 함께 보고하기로 함
- 복구는 그 자리에서 툭 건드리는 작은 정책을 따로 학습 (자기 칸 벽 스치는 건 괜찮고, 다른 퍽은 닿으면 안 됨)
