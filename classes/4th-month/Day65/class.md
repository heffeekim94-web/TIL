# 11/06 실습에서 배운 것

강의 노트(강의 DB)에 11/06 행이 없어서, 오늘 YOLO 작업에서 배운 것을 정리했어요.

## 1. 처음 보는 영상으로 채점해야 진짜 점수

- 같은 영상에서 뽑은 프레임은 몇 초만 떨어져도 거의 같은 장면 → train 과 test 가 같은 영상이면 점수가 후함
- 기존 test 52장(train 과 같은 영상) 1등 모델이, 학습에 안 쓴 06 영상에서는 꼴찌 (0.705 → 0.448)
- 그래서 val · test 는 **영상 통째로** 떼어 두기 (영상 단위 분리)

## 2. train · val · test 의 역할

| | 역할 | 몇 번 보나 |
|---|---|---|
| train | 모델이 배우는 사진 | 매 epoch |
| val | **내가** 설정 · 모델을 고르는 사진 | 몇 번이든 |
| test | 마지막 성적 | 다 정한 뒤 **한 번** |

- test 를 보고 고르기를 반복하면 그 test 사진에만 맞는 모델을 고르게 됨
- 좋은 방법: val 로만 고름 → 설정을 잠금 → test 한 번 → 그 숫자를 보고하고 더 고치지 않음

## 3. seed

- seed = 학습 중 무작위(사진 순서 · 증강 · 새 층 초기값)의 시작 번호
- 같은 설정이라도 seed 만 바꾸면 mAP 가 0.01~0.03 달라짐 → 한 번 이긴 걸로는 운인지 모름
- 비슷한 후보는 seed 3개로 돌려 평균 · 흔들림을 보고, **판단 기준은 결과를 보기 전에** 정함

## 4. 이상적인 val 곡선과 우리 곡선

- 이상적: 빨리 오르다가 평평 (epoch 간 ±0.005), best 가 평평한 구간 뒤쪽
- 우리: epoch 1 부터 0.80 근처, ±0.02~0.07 흔들림 → val 이 작고(68장) 쉬워서(같은 영상) 상자 1개에 점수가 움직임
- 이런 val 로 고른 best.pt 는 운 좋게 튄 epoch 일 수 있음

## 5. 라벨링 시간 줄이기

- 비슷한 프레임은 빼고 다른 장면만 남김 (286 → 89장)
- 지금 모델의 예측을 초벌 라벨로 올리고 틀린 것만 고침 (CVAT YOLO 1.1)
- 상자는 회전하지 않음: 모델이 똑바른 상자만 내고, YOLO 1.1 은 회전 정보를 저장하지 않음

## 6. 바운딩 박스

- 물체를 둘러싼 사각형 = 무엇(클래스) + 어디(상자). YOLO 라벨 한 줄 = `클래스 중심x 중심y 너비 높이` (모두 사진 크기로 나눈 0~1)
- 맞았는지는 IoU(겹친 넓이 ÷ 합친 넓이): mAP50 = IoU 0.5 이상이면 맞음, mAP50-95 = 0.5~0.95 를 평균 → 상자가 딱 맞아야 높음
