# 강의 정리: 01 AI·LLM 응용 베이스 (11/18)

> 작성: 김혜민 · 2026-11-18 (수)
> 강의 자료: [01 AI·LLM 응용 베이스 · 20시간 · v1.2 (드라이브 PPT)](https://docs.google.com/presentation/d/1YlBKAhh7dICAgIp0Bg7Vr2Yjf_mgCJuyOC6CRk7OA4w/edit) (11/18 추가, 63장)

오늘은 **LLM · VLM · VLA 단원의 강의 자료를 받은 날**이에요. 20시간 (10단원 × 2시간) 짜리 과정이고, 모든 단원이 "입력 계약 → 검증 코드 → 비교 실험 → 실패 분석" 으로 끝나요.

- LLM 은 다음 토큰 확률을 계산하는 모델. 확률이 높은 답 ≠ 사실 ≠ 실행해도 되는 명령
- 로봇에 LLM 을 붙일 땐 출력이 아니라 **검증과 보류 기준** 이 핵심
- 로컬 LLM (Ollama) 은 HTTP API 에 JSON Schema 를 넣어 구조화된 답을 받음
- CNN → CLIP · BLIP → VLA 순서로 "보는 모델" 에서 "움직이는 모델" 로 감
- VLA 를 새 로봇에 쓰려면 행동 규격과 어댑터를 먼저 정해야 함

## 2. LLM 기본

- 흐름: 텍스트 → **토큰 ID** (tokenizer) → **임베딩** (임베딩 행렬에서 그 ID 의 행) → 문맥 처리 → 다음 토큰 점수 → 고른 토큰을 문맥에 붙이고 반복
- 토큰은 단어와 1:1 이 아님. 나누는 방식 · 어휘 크기 · 벡터 차원은 모델마다 다름
- **자기회귀**: P(x1…xn) = ∏ P(x(t) | x(<t)). 문장 확률을 조건부 확률의 곱으로 쪼갬
- **학습 vs 추론**: 학습은 손실 → `loss.backward()` → `optimizer.step()` 으로 가중치 갱신. 추론은 `model.eval()` + `torch.no_grad()` 로 가중치 고정
- **Attention**: 입력에서 Q · K · V 를 만들고 softmax(QKᵀ/√d_k)·V. 가중치가 [0.8, 0.2] 면 출력 = 0.8v1 + 0.2v2
- **Transformer** (2017, Attention Is All You Need): 인코더 · 디코더, 위치 인코딩, 잔차 연결, 다중 헤드. 원 논문 구조와 생성형 LLM 구조는 다름 (생성형은 디코더 쪽)

<br>

## 3. 로봇 명령으로 쓸 때

- **입력 계약**: `instruction` / `object_id` / `location_id` / `observed_at` 을 분리. 모델의 사전 지식이 현재 로봇 상태를 대신하면 안 됨
  - 빨간 상자가 2개 → 어느 건지 물어봄, 목적지 A 가 지도에 없음 → 실행 보류
- **환각**: 정보가 모자라도 그럴듯한 답을 만듦. 긴 문맥에선 정보를 빠뜨리거나 잘못 잇기도 함
- **두 가지 성공률을 따로 봄**: 형식 성공률 (구조 검사 통과 / 전체) vs 작업 성공률 (실제 완료 / 전체)
- 오류 종류: 의미 오류 (없는 대상 · 장소를 만듦) / 필드 오류 (누락 · 오타 · 타입) / 상태 불일치 (오래된 관측 · 실행 불가 상태)
- 평가 전에 요청별 **기대 행동을 고정**. 보류가 기대 행동이면 올바른 보류도 정답
- 실습: 명령 20개 (정상 8 · 모호 4 · 없는 장소 4 · 금지 동작 4) 로 실패 유형별 건수 세기
- temperature 를 낮추면 답이 덜 흔들릴 뿐, 사실이 되는 건 아님

<br>

## 4. 프롬프트 · 작업 분해

- 제로샷 (예시 0) · 원샷 (1) · 퓨샷 (여러 개). 예시는 출력 형식과 판단 경계를 알려 줌
  - 원샷은 예시 편향, 퓨샷은 입력이 길어져 지연 · 비용이 늘어남
- 비교 실험은 모델 · 평가 입력 · 출력 스키마 · 생성 설정을 고정하고 **예시 수만** 바꿈
- 퓨샷 구성 예: 정상 이동 / 없는 장소 보류 / 모호한 물체 확인 요청
- **CoT** (Chain-of-Thought, 2022): 중간 단계를 보여 주는 예시로 추론 성능을 올림. 로봇에선 "관찰 가능한 하위 작업 + 성공 조건" 으로 바꿔 씀
- 운반 과제 = 대상 확인 · 접근 · 집기 · 이동 · 놓기 · 결과 확인. 단계마다 전제조건 · 완료조건 · 실패 전이
- 집기 실패 → 이동 단계로 못 넘어가게 막고 원인 기록 (통과 조건: 실패 뒤 이동 명령 0건)

<br>

## 5. JSON · Schema · API

- JSON = 값을 적는 형식, Schema = 구조 · 값 규칙, API = 프로그램끼리 요청 · 응답 규약
- 검사 순서: JSON 해석 → 스키마 검사 → 의미 · 현장 상태 검사
- 스키마 키워드: `required` (필수 키), `enum` (허용 값), `additionalProperties: false` (선언 안 한 키 거부)
- 예: `{"action":"navigate","target":"A","timeout_s":20}` — action 은 navigate · inspect · hold 만, target 은 등록된 장소 ID 만
- **LLM API**: 모델은 명령 후보만 만들고, 검증 · 실행 결정은 프로그램이 함
  - 전체 지연 = 요청 준비 + 네트워크 + 생성 + 검증 + 실행 대기 → 구간별로 시각 기록
  - API 키는 환경변수, 모델 ID · SDK 버전은 기록에 고정
  - 모델 재요청과 로봇 동작 재실행을 분리. `command_id` 로 같은 명령이 두 번 실행되지 않게
- 실습 파일: `labs/01_contract.py` (검증기), `labs/02_llm_api.py` (MOCK → 실제 API)

<br>

## 6. 로컬 LLM (Ollama)

- 메모리 = 가중치 + KV cache + 실행 버퍼. 가중치 하한 ≈ 파라미터 수 × 비트 수 / 8 (4B × 4bit ≈ 2GB)
- 설치는 스크립트를 받아 내용을 확인한 뒤 실행. OS · Ollama · 드라이버 버전 기록
- 서비스가 이미 돌면 `ollama serve` 를 또 띄우지 않기. 연결 오류는 포트 11434 → 서비스 상태 → 로그 순서
- 실습 모델: `qwen3:4b` (`ollama pull` → `run` → `list` / `ps`)
- 로컬 API: `POST localhost:11434/api/chat` 에 `model · messages · format(JSON Schema) · stream:false` → `message.content` 를 검증기로
- 오류 진단: 연결 거부 (서버 · 포트) / 모델 없음 (태그) / timeout (로딩 · 문맥 길이 · 장비 부하) / JSON · 의미 오류는 따로 분류

<br>

## 7. CNN

- 작은 필터를 여러 위치에 쓰는 국소 연산 + 가중치 공유. 층이 깊어질수록 단순 패턴 → 조합 특징
- **출력 크기 = floor((N + 2P − K) / S) + 1** → N=32, K=3, P=1, S=1 이면 32
- 합성곱은 원소별 곱의 합 (Conv2d 는 필터를 뒤집지 않는 교차상관)
- ReLU = max(0, x), MaxPool = 영역 최댓값, Softmax = 합이 1 이 되게 정규화. CrossEntropyLoss 에는 softmax 전 logit 을 넣음
- 텐서 shape N×C×H×W. `Conv2d(3, 8, 3, padding=1)` 에 [1,3,32,32] → [1,8,32,32] (채널만 바뀜)
- 손실 L = −ln p(정답): p=0.9 → 0.105, p=0.1 → 2.303
- 학습 (가중치 갱신) · 검증 (설정 선택) · 시험 (최종 평가) 분리. 같은 연속 촬영 장면은 한 세트에만
- 분류는 "무엇" 만. 집을 위치는 검출 · 깊이 · 좌표 변환이 더 필요
- 실습: `labs/03_cnn.py` (수계산과 shape 대조, 혼동행렬 · 오분류 분석)

<br>

## 8. CLIP · BLIP

- **CLIP** (2021): 이미지 인코더와 텍스트 인코더의 벡터를 cos 유사도로 비교 → 후보 문장 순위. 유사도는 물체가 있을 확률도, 3D 위치도 아님
- **BLIP** (2022): 사진을 보고 캡션 · 답변을 만듦. 캡션의 대상 · 색 · 수량 · 관계를 사진에서 확인하고 없는 물체 언급은 오류로 기록
- VLM 보류 기준: 유사도가 낮거나 후보끼리 점수 차가 작으면 보류. 임계값은 평가 데이터로 정함
- 실습: `labs/04_embeddings.py` (빨간 상자 / 파란 상자 / 빈 작업대)

<br>

## 9. VLA

- **a(t) = π(o(t), l)**: 관측 o(t) + 언어 지시 l → 정책 π → 행동 a(t)

| 구분 | 입력 | 출력 | 로봇에서 역할 |
|---|---|---|---|
| LLM | 문장 · 상태 | 문장 · 계획 | 고수준 작업 분해 |
| VLM | 영상 · 문장 | 설명 · 표현 | 장면 · 대상 이해 |
| VLA | 영상 · 언어 · 상태 | 행동 | 학습된 행동 정책 |

- **RT-2** (2023): 로봇 행동을 토큰으로 바꿔 영상 · 언어와 같이 학습. 행동 토큰은 로봇 행동 규격으로 다시 풀어야 함
- **OpenVLA** (2024): 시각 인코더 → projector → 언어 모델 → 행동 토큰. 코드에서 볼 곳: 관측 전처리 · 행동 역정규화 · 로봇별 통계
- **SmolVLA** (2025): 작은 VLA + 비동기 추론 · 실행. 관측 시각과 실행 시각 차이, 오래된 행동 버리기가 포인트
- Gemini Robotics 공식 시연도 봄
- **행동 어댑터**: 모델 출력 → 역정규화 → 좌표 · 단위 변환 → 실행 검사. 영상 · 언어만으로 모든 로봇에 바로 쓸 수 없음
- 7차원 행동은 예시 규격일 뿐. 관절 · TCP · 그리퍼 중 무엇인지 명시해야 함
