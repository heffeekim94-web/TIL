## 오늘 배운 것
- 모델은 입력 → 출력 함수에 데이터로 배운 숫자 (가중치) 를 채운 것이다. 숫자 파일만으로는 안 돌고, 돌리는 코드와 환경이 같이 있어야 한다
- "모델" 은 AI 모델 · 동역학 모델 · 3D 모델 · 로봇 모델 (URDF) 처럼 여러 뜻으로 쓰인다
- 행동을 관절 공간으로 내는 정책은 그 로봇에 묶이고, 작업 공간 (도구 자세) 으로 내면 IK 로 다른 팔에도 옮길 수 있다. 이걸 넘으려는 게 cross-embodiment
- LLM · VLM 은 느리고 좌표가 거칠어서 팔을 직접 움직이기보다 "무엇을 · 언제 · 다시 할지" 정하는 상위 판단에 쓴다
- 파이의 turtlebot3 패키지와 OpenCR 펌웨어는 다른 컴퓨터에서 도는 다른 프로그램이다. bringup 은 펌웨어를 넣어 주지 않는다
