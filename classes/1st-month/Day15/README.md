## 고유값, 고유벡터

일반 벡터는 A를 곱하면 방향이 돌지만 

고유 벡터는 

1. 방향이 유지되고 
2. 크기만 $\lambda$배 된다

이차 방적식을 사용하여 근/계수 관계를 구한다. 

$A\mathbf{v}=\lambda\mathbf{v} \quad (\mathbf{v} \not= 0)$  

영이 아닌 해가 존재 하려면 **특성방정식(characteristic equation)**을 사용한다:
<br> $(A-\lambda I)\mathbf{v}=0 \quad$ 
<br> $det(A-\lambda I)=0$ 

이는 n차 다항방정식이고 근이 고유값을 의미한다.

검산 공식을 기억해두면 좋다:
```math
\sum_i \lambda_i = \text{tr}\,A \ (\text{대각합}), \qquad \prod_i \lambda_i = \det A
```

공진과 안전성을 예비하기 위한 공식

1940년 미국 타코마 다리는 시속 68 km의 바람에 붕괴했다. 구조물이 견딜 수 있는 하중의 문제가 아니라, **바람의 주기가 다리의 고유진동수와 맞물린 공진이 문제였음**. 이 고유진동수가 수학적으로는 행렬의 고유값이다.

건물의 내진 설계, 자동차 서스펜션 튜닝, 회전축의 위험속도 계산, 구글의 PageRank 알고리즘까지 — "시스템의 본질적 성질" 을 묻는 문제는 결국 고유값 문제로 귀결됨.

요약:

**고유벡터**는 
```
1. 방향이 유지되고 
2. 크기만 $\lambda$배 된다

특정방정식(characteristics equation)을 사용한다. 

고유 진동수, 변하지 않는 회전축, 파동함수, 주응력 방향이다. 

시스템의 본질적 성질 이다. 
```

## 회진행렬

회진행렬의 고유벡터 = 회전축

오일러의 회전 정리 - 모든 3D는 한 축을 기준으로 회전하는.. 선형대수적 증거

3차원의 회전행렬의 고유값은:
<br> 1. $\lambda_1=1(실수)$ --> 회전축
<br> 2. $\lambda_{2,3}=\cos\theta\pm  i \sin\theta(켤레복소수)$

1.번은 곧 $Rn = n, 즉 축 위에 벡터는 회전해도 그대로라는 뜻

대각합에서 회적가이 나온다. 

```math
\text{tr}\,R = 1 + 2\cos\theta \quad\Longrightarrow\quad \theta = \arccos\frac{\text{tr}\,R - 1}{2}
```

회전행렬에서 쿼터니언을 얻는 변환 --> 고유값

쿼터니언 - 결과

고유값 - 그 결과가 나온 이유

요약:
```
회진축을 구하려면 회진행렬의 고유값을 구할 것 

오일러의 회전 정리가 증명해준다

```

## 대각화 - 행렬이 가장 단순해지는 좌표계


**대각화(diagonalization)**:

$n\times n$ 행렬 $A$ 가 $n$ 개의 선형독립인 고유벡터를 가지면, 이들을 열로 쌓은 $P$ 에 대해

```math
A = P\Lambda P^{-1}, \qquad \Lambda = \text{diag}(\lambda_1, \ldots, \lambda_n)
```
가 성립하는 것. 

순서:
```
표준 좌표계 -> 고유벡터 좌표계 -> 다시 표준 좌표계
```
<br>

방정식:

**행렬 거듭제곱**:
<br> $A^k = P\Lambda^kP^{-1}$ , A를 대각 원소만 k제곱

**미분방정식**:
<br> $x" = Ax$ 의 해는 
<br> $x(t) = \sum c_i e^{\lambda_it}v_i$
- 고유값의 실수부가 모두 음수이면 해가 0
- 제어공학의 "극점이 좌반평면에 있어야 안정하다"
