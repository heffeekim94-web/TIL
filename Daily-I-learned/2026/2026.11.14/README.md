## 문제점
- 라벨 박스로 잘라도 판독은 143장 중 10장. 폭 120 px 미만은 0장
- 광각 배포 모델에 손목 사진으로 이어 학습하면 광각 성능이 떨어지고 퍽 클래스를 잊어버릴 수 있음
- Jetson 손목 모델에 바코드 클래스가 없음 (시뮬 전용 퍽 분할 모델)




<br>

## 해결 방법

- 손목 바코드 1클래스 모델을 따로 만들고, 시작 가중치만 배포 모델에서 가져옴
- 영상 단위로 나눔: train = pa06 영상, val = 로봇 손목 1219 영상
- 노트북에 "예측 박스로 잘라 판독" 셀을 넣어 찾기 · 읽기를 같이 확인



<br>

## 결과

- 라벨 143장 (pa06 123 · 로봇 손목 20), 박스가 스티커에 딱 맞음
- 판독: 화면 전체 1장 → 박스로 잘라 10장 (200 px 이상 6/21, 120–200 px 4/45, 120 px 미만 0/73)
- Jetson 손목 모델 = jje 계정, YOLO26n-seg 8클래스, 시뮬 데이터만, 바코드 없음
- 노트북 시험 (CPU 3 epoch): val 바코드 16/16 찾음 (배포 모델 11/16), 오검출 4
