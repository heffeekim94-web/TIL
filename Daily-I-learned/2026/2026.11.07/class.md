# 11/07 실습에서 배운 것

주말이라 수업은 없었고, YOLO 작업에서 배운 것을 정리했어요.

## 1. 점수와 로봇 기준은 다를 수 있음

- mix 가 06 mAP50-95 에서 seed 3개 모두 +0.1 정도 이김 → 하지만 mAP50 은 비슷
- mAP50-95 는 상자가 얼마나 **딱 맞는지**까지 보고, 로봇은 conf 0.5 에서 **찾았는지**를 봄
- conf 0.5 에서는 실물만 모델이 7개 더 맞힘 → 점수 하나만 보면 로봇에 맞지 않는 모델을 고를 수 있음
- 그래서 mAP 와 conf 0.5 혼동 행렬을 같이 보고, 판단 기준은 미리 적어 둠

## 2. 카메라가 해야 할 일에 맞춰 채점하기

- 광각은 참고, RealSense 로 확정 → 광각은 가까운 것만 맞히면 됨
- 거리는 사진 속 크기로 바꿔 씀: 1.2 m 에서 퍽 짧은 변 약 20 px → 기준 18 px (렌즈 가장자리는 작아짐)
- 크기는 거리에 반비례: 1.0 m 는 1.2 m 의 약 1.17배 → 약 23 px
- 먼 라벨을 지우기만 하면 "빨간 물체 = 배경"으로 배움 → 라벨은 두고 채점에서만 빼거나, 사진에서 회색으로 가림

## 3. 합성을 실물처럼 (sim-to-real)

- 실물 사진을 재 보니 흐린 게 아니라 거칠고 밝음: 고주파 4배, 잡음 1.7배, 밝기 110 → 134
- 쉬운 방법: 학습 때 합성 사진에 카메라 효과 (밝기 · 대비, 채도, 선명화, 센서 잡음, JPEG 압축) — 압축은 카메라처럼 맨 마지막
- 그 밖: 카메라 렌즈 왜곡 · 자세 맞추기, 실물 바닥 · 벽 사진을 텍스처로, 도메인 랜덤화, 합성 → 실물 그림 변환(CycleGAN)
- 효과는 픽셀만 바꿔서 상자 라벨은 그대로
- 합성을 오래 학습하면 합성의 특징(깨끗한 가장자리 등)에 맞춰져 실물 점수가 떨어짐 → 1단계는 짧게

## 4. 1단계 · 2단계

## 5. 그래프 읽기: Precision-Confidence 곡선

- x 축은 epoch 이 아니라 **문턱값**: 그 값 이상인 예측만 남겼을 때 맞은 비율
- 오른쪽(문턱값 높음)은 남은 예측이 몇 개뿐이라 하나만 틀려도 크게 흔들림 → 발산이 아님
- "all classes 1.00 at 0.904" 는 거의 다 놓친 상태 → 문턱값은 F1 곡선으로 고름
