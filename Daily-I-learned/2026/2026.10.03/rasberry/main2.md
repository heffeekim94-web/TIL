[main.py](main.py)는 라즈베리파이에서 키보드로 입력한 명령을 OpenCR 보드에 보내고, 보드가 보낸 답을 화면에 보여 주는 프로그램이에요. 위에서부터 묶음별로 설명할게요.

## 1~6줄: 설명과 준비물 불러오기

| 줄 | 뜻 |
|---|---|
| 1 | 이 파일이 무슨 프로그램인지 적은 설명문이에요. 실행에는 영향이 없어요. |
| 2 `import select` | 키보드와 보드 중 **어느 쪽에 새 데이터가 왔는지** 동시에 지켜보는 도구예요. |
| 3 `import sys` | 키보드 입력(`sys.stdin`), 오류 출력, 프로그램 종료에 써요. |
| 4 `import time` | 기다리기(`sleep`)에 써요. |
| 6 `import serial` | USB 시리얼 통신 라이브러리(pyserial)예요. OpenCR과 대화하는 데 써요. |

## 8~13줄: 설정값

| 줄 | 뜻 |
|---|---|
| 8 `PORT` | OpenCR이 연결된 USB 장치 이름이에요. |
| 9 `BAUDRATE` | 통신 속도예요. 스케치의 `Serial.begin(115200)`과 **반드시 같아야** 해요. |
| 10~13 `HELP` | 사용법 안내문이에요. 시작할 때와 `help`를 입력했을 때 출력돼요. |

## 16~18줄: `send_command()`, 보드로 명령 보내기

- 17줄: 입력한 글자의 앞뒤 공백을 지우고(`strip`), 끝에 줄바꿈(`\n`)을 붙여 바이트로 바꿔(`encode("ascii")`) 보냅니다. OpenCR은 `\n`을 받아야 "명령 한 줄이 끝났다"고 판단해요(스케치 349줄).
- 18줄: `flush()`로 모아 둔 데이터를 즉시 내보내요.

## 21~55줄: `main()`, 프로그램의 본체

**연결 준비 (22~27줄)**
- 22: 시리얼 포트를 엽니다. `with`를 쓰면 프로그램이 끝날 때 포트가 자동으로 닫혀요. `timeout=0.1`은 읽을 때 최대 0.1초만 기다린다는 뜻이에요.
- 23: 2초 기다려요. 포트를 열면 OpenCR이 재시작될 수 있어서 준비될 시간을 줍니다.
- 25: 빈 줄을 보내서, 보드에 반쯤 남아 있던 입력을 한 번 끊어 줘요.
- 26: 사용법을 출력해요.
- 27: `pending`은 보드에서 받은 글자를 **한 줄이 완성될 때까지 모아 두는 상자**예요.

**무한 반복 (29~49줄)**
- 30: 키보드와 보드를 **0.2초 동안 동시에 지켜보다가** 데이터가 온 쪽을 알려 줘요.
- 31~37: **보드에서 데이터가 왔을 때**
  - 32: 도착한 바이트를 모두 읽어 `pending`에 붙여요.
  - 33~34: 줄바꿈이 있으면 한 줄씩 잘라 냅니다.
  - 35: 바이트를 글자로 바꿔요. 깨진 글자는 `?` 같은 기호로 대신해요.
  - 36~37: 빈 줄이 아니면 화면에 출력해요. `MOVING XY ...`, `DONE ...` 같은 메시지가 여기서 보여요.
- 38~49: **키보드 입력이 왔을 때**
  - 39: 한 줄을 읽어요.
  - 40~41: 입력이 끝났거나(`Ctrl+D`) `q`면 반복을 빠져나가요.
  - 43~44: `help`면 보드에 보내지 않고 사용법만 출력해요.
  - 45~47: 나머지 명령은 보드로 보내요.
  - 48~49: 한글처럼 ASCII가 아닌 글자를 입력하면 오류가 나는데, 프로그램이 죽지 않게 안내만 출력해요.

**종료 처리 (50~55줄)**
- 50~51: `Ctrl+C`를 눌러도 오류 메시지 없이 조용히 넘어가요.
- 52~55: `finally`는 **어떻게 끝나든 반드시 실행**돼요. 보드에 `x`(정지)를 보내서, 프로그램을 꺼도 모터가 계속 움직이지 않게 하는 안전장치예요.

## 58~63줄: 프로그램 시작점

- 58: 이 파일을 직접 실행했을 때만 아래 코드가 돌아요. 다른 파일에서 `import`하면 실행되지 않아요.
- 60: `main()`을 실행해요.
- 61~63: USB가 빠졌거나 포트를 찾지 못하면 `시리얼 연결 오류: ...`를 출력하고 종료 코드 1로 끝내요.

## 한 줄 요약

> 키보드 입력 → `send_command()` → USB → OpenCR `loop()` → 모터
> 모터 상태 → OpenCR `Serial.println()` → USB → 31~37줄 → 화면 출력

이 두 방향을 `select`로 동시에 처리하는 구조예요.
