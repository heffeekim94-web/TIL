# OpenCR 두 모터 동시 제어

2026.10.03

## 오늘의 목표

기존에는 X축과 Y축 모터를 각각 조절했다.
두 축의 목표각도와 속도를 한 줄로 입력해 함께 움직이도록 카메라 제어 코드를 확장했다.

## 장비와 기준

| 항목 | 설정 |
|---|---|
| 보드 | OpenCR |
| 모터 | DYNAMIXEL XM430-W350 2개 |
| 통신 | Protocol 2.0, 1 Mbps |
| X축 | 좌우 회전, pan ID11 |
| Y축 | 상하 회전, tilt ID12 |
| 각도 기준 | 저장된 홈 위치 |
| 속도 단위 | °/s |

각도는 명령 입력 순간의 위치가 아니라 저장된 홈을 기준으로 계산한다.
모터 내부 위치 PID를 사용하는 카메라 위치 제어이며, 과제의 OpenCR 외부 P 제어와 구분한다.

## 변경 전후 비교

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 이동 입력 | `pan 30`, `tilt -10` 각각 입력 | `move 30 -10 5 3` 한 번 입력 |
| 속도 설정 | `speed 5`로 공통 속도 설정 | X·Y축 속도를 각각 입력 |
| 출발 방식 | 한 축 이동 후 다른 축 이동 | 두 축에 한 패킷으로 명령 전달 |
| 완료 판정 | 이동 중인 한 축의 도착 확인 | 두 축 모두 도착해야 완료 |
| 각도 기준 | 저장된 홈 기준 | 동일하게 유지 |

## 변경 전 사용 과정

```text
speed 5
pan 30
```

공통 속도를 설정하고 X축을 홈 기준 +30°로 이동시킨다.
X축 이동이 끝난 후 다음 명령으로 Y축을 이동시킨다.

```text
tilt -10
```

이동 중 새 이동 명령은 거부되므로, 도착을 기다리거나 `x`로 정지해야 다음 명령을 실행할 수 있었다.

## 변경 후 사용 과정

```text
move X각도 Y각도 X속도 Y속도
```

예시:

```text
move 30 -10 5 3
```

| 축 | 목표각도 | 속도 상한 |
|---|---|---|
| X축 ID11 | 홈 기준 +30° | 5°/s |
| Y축 ID12 | 홈 기준 -10° | 3°/s |

두 모터는 함께 출발한다. 이동 거리와 축별 속도에 따라 도착 시간은 달라질 수 있다.
속도는 모터가 지원하는 단위로 내림 처리되며, 적용된 프로파일 속도는 `MOVING XY`에 표시된다.

## 코드 처리 과정

1. 네 입력값의 형식과 범위를 검사한다.
2. 각 모터의 속도 한계를 확인하고 두 축을 준비한다.
3. 홈 기준 각도를 엔코더 목표 위치로 변환한다.
4. Sync Write 한 패킷으로 두 모터에 가속 프로파일·속도·목표 위치를 전달한다.
5. 각 모터의 목표 위치를 다시 읽어 명령 적용 여부를 확인한다.
6. 두 축의 현재 위치와 속도를 주기적으로 확인한다.
7. 두 축 모두 도착하면 `DONE XY`를 출력하고 토크를 유지한다.

Sync Write에는 각 모터의 개별 응답이 없으므로, 전송 후 목표 위치를 읽어 확인한다.

## 추가한 기능

| 기능 | 역할 |
|---|---|
| `parseMove()` | 네 입력값 검사, 잘못된 입력 전체 거부 |
| `moveBoth()` | 축별 속도·목표 계산 및 동시 명령 전송 |
| 동시 이동 상태 관리 | 두 축의 도착 여부와 시간 초과 확인 |

내부 배열은 Y축 ID12, X축 ID11 순서이므로 사용자 입력 X·Y를 내부 순서에 맞게 변환한다.

## 입력 범위

| 항목 | 입력 범위 |
|---|---|
| X각도 | -90..90° |
| Y각도 | -135..135° |
| X속도·Y속도 | 1.374..30°/s, 각 모터의 속도 한계 이내 |

각도 범위는 소프트웨어 시험 범위이며, 실제 장비의 기계적 이동 여유를 측정한 값은 아니다.

## 기존 명령

| 명령 | 동작 |
|---|---|
| `pan 30` | X축 단독 이동 |
| `tilt -10` | Y축 단독 이동 |
| `speed 5` | 단일 축 이동과 순차 홈 복귀의 공통 속도 설정 |
| `h` | Y축 홈 복귀 후 X축 홈 복귀 |
| `x` | 이동 취소 후 현재 위치 유지 |
| `off` | 두 모터의 토크 해제 |
| `p` | 상태 확인 |

`move`는 입력한 축별 속도를 사용한다. 이동 중 새 목표를 입력하려면 먼저 `x`로 정지한다.
`off`는 카메라가 무게로 내려갈 수 있으므로 장비를 지지한 상태에서 사용한다.

## 배운 점

두 모터를 함께 움직이려면 입력을 한 줄로 묶는 것뿐 아니라 실제 모터 명령도 함께 전달해야 한다.
이번에는 Sync Write로 두 축의 속도와 목표 위치를 한 패킷에 담았다.

함께 출발하는 것과 같은 시각에 도착하는 것은 다르다.
이번 변경은 동시 출발을 지원하며, 도착 시간을 맞추기 위한 속도 자동 계산은 포함하지 않는다.
